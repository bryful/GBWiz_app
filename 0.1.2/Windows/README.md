# GBWiz 0.1.2

ゲームボーイ／ゲームボーイカラーの『ウィザードリィ』『ドラゴンクエストIII』を快適に遊ぶためのプレイヤーです。倍速、途中保存、マップ表示、経験値・お金の倍率変更などを利用できます。

ゲームのROMは付属しません。ご自身で用意したROMファイルを使用してください。

## 対応ゲーム

- ウィザードリィ外伝I・II・III（GB版）
- ウィザードリィI・II・III（GBC版）
- ドラゴンクエストIII（GBC版）

ドラゴンクエストI＆IIは対応対象外です。ROMの版によって、一部の支援機能を利用できない場合があります。

## はじめかた

### Windows

1. このフォルダーを好きな場所に置きます。
2. フォルダー内の`GBWiz.exe`を起動します。`SDL2.dll`は同じ場所に置いてください。
3. 遊びたいROMファイルを選びます。`Rom`フォルダーへ入れておくと選びやすくなります。

### Android

Android 8.0以降に対応しています。

1. `../Android/GBWiz-0.1.2.apk`を端末へコピーし、開いてインストールします。端末の案内に従って、使用したファイル管理アプリなどからのインストールを許可してください。
2. GBWizを起動し、保存先フォルダーを選びます。通常は`Documents/GBWiz`を使います。
3. 遊びたいROMを選びます。初期のROMフォルダーは`Documents/GBWiz/rom`です。別のフォルダーも選択できます。

正式版0.1.0／0.1.1からは上書き更新できます。更新前に保存フォルダーをバックアップしてください。

開発版から更新できない場合は、先に`Documents/GBWiz`をバックアップし、開発版をアンインストールしてから正式版を入れてください。起動後は、これまで使用していた保存フォルダーを選択します。

## 基本操作

Androidでは画面のタッチボタンを使えます。Windows／AndroidともXboxコントローラー・Proコントローラーに対応しています。

| 操作 | Windowsのキーボード | コントローラー |
|---|---|---|
| 移動・項目選択 | 矢印キー | 十字キー |
| A／B | X／Z | 右／下のフェイスボタン |
| Start／Select | Enter／右Shift | Start／Select（＋／−） |
| 機能メニュー | F1／Esc | 左スティック押し込み |
| スロット1へ保存／読込 | F5／F8 | LT／右スティック押し込み |
| 迷宮マップ | M | RT／ZR |

A・Bの配置は機能メニューで入れ替えられます。

**速度・倍率・ON／OFFは、項目を選んで左右で変更します。** Aでは変更しません。Androidでは項目の左右をタップして変更できます。

機能メニューの「ROM選択」でゲームを切り替えられます。「リセット」は選択するとすぐにゲームを再起動します。

## 便利な機能

### 倍速と途中保存

- 速度は通常・1.5倍・2倍・3倍・4倍から選べます。主要な場面ではBGM・効果音を通常速度で再生します。
- ステートセーブは5スロットあります。保存した時点から再開できます。
- ステートを読むと、キャラクターへの変更も含めて保存時点へ戻ります。ゲーム内の通常セーブも併用してください。

### 経験値・お金の倍率

対応7作品すべてで、戦闘後の経験値とお金をそれぞれ通常・8・16・32・64・128・256倍にできます。両方を同時に設定できます。すでに持っている経験値やお金には適用されません。

### Wizardryの支援機能

外伝I〜III・GBC版I〜IIIの全6作品で利用できます。機能メニューから設定してください。Androidでは「サポート」を開きます。

| 機能 | 使いかた・効果 |
|---|---|
| 作成ボーナス最大 | 新規キャラクターのボーナスを外伝では30、GBC版では60にします。 |
| MP消費なし | パーティー全員の呪文によるMP消費を止めます。現在MPが0の段階は使えないため、宿屋などで回復してください。 |
| 全呪文習得 | 対象キャラクターを選び、全呪文を覚えさせ、現在MPと最大MPを9にします。戦闘中は実行できません。 |
| 属性変更 | 対象キャラクターを選び、「属性」の左右操作で善・中立・悪を変更します。 |
| 善悪混合パーティー | 属性を変えずに善悪混合の加入を許可します。OFFに戻しても現在のパーティーは解散しません。 |
| ロゴスキップ | 起動時のメーカーロゴをスキップします。 |

GBC版で酒場の候補一覧を開いているときに善悪混合をONにした場合は、Bで戻って一覧を開き直してください。

### 迷宮マップと移動

Wizardry全6作品で、迷宮内・キャンプ中にマップを開けます。Androidは「マップ」ボタンを使います。戦闘中は開けません。

1. 矢印キー・十字キーで移動先を選びます。
2. PageUp／PageDown、LB／RBで階層を変更します。Androidでは画面の階層ボタンも使えます。
3. Aで移動、Bでキャンセルします。

**移動直前にスロット1へ自動保存するため、以前のスロット1は上書きされます。** 保存に失敗した場合は移動しません。

マップには開閉した扉など一部の変化が反映されません。直接移動した場合、歩いて到着したときとイベントの動きが異なることがあります。

## セーブデータとバックアップ

| 環境 | 保存先 |
|---|---|
| Windows | `%APPDATA%\GBWiz` |
| Android | 初回に選んだ保存フォルダー。通常は`Documents/GBWiz` |

Windowsでは、エクスプローラーのアドレス欄に`%APPDATA%\GBWiz`を入力すると開けます。

セーブはROMファイル名に対応しています。**ROMの名前を変えると、以前のセーブが見つからなくなる場合があります。** 更新やキャラクター編集の前には、保存フォルダー全体をコピーして保管してください。

## 0.1.2の更新内容

MP消費なしを外伝III・GBC版Wizardry I〜IIIへ追加しました。外伝IIIは錬金術師の呪文も対象です。これでWizardry全6作品で利用できます。

## 困ったとき

- **支援機能が選べない：** 対応ゲーム・対応するROMの版か確認してください。キャラクター操作は戦闘終了後に試してください。
- **MP消費なしでも呪文を使えない：** 現在MPが0の場合や、未習得の呪文には効果がありません。
- **以前のセーブが見つからない：** ROMファイル名と保存フォルダーが以前と同じか確認してください。
- **Androidで更新できない：** 上の「はじめかた」にある開発版からの移行手順を確認してください。

不具合は[報告ページ](https://github.com/bryful/GBWiz_app/issues)へ、バージョン・端末・ゲーム名・操作手順と症状をお知らせください。ROMファイルは添付しないでください。
