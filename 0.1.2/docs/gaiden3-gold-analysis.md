# 外伝IIIのお金倍率：解析と実装

戦闘終了時に原作が分配した1人分のお金を倍率化し、×1／×8／×16／×32／×64／×128／×256を選べるようにしました。経験値倍率とは独立して設定できます。

| 用途 | CPUアドレス |
|---|---|
| 人数による除算 | バンク4 7092〜70A0、共通048E |
| 1人分の金額の格納呼出 | バンク4 70A6〜70AB（ROMオフセット130A6〜130AB） |
| 金額の作業領域 | CAD9〜CADC、符号なし32ビット・リトルエンディアン |
| 共通4バイト格納 | 029E〜02A9、4バイト目の書込後PC=02A6 |
| 倍率化を許可する復帰先 | 70AC |
| 現在のROMバンク管理値 | CAC7=4 |
| 各メンバーへの加算 | バンク4 70AD〜70D3 |
| キャラクター作業中の所持金 | CB38〜CB3B（CB1Fレコード+19h） |
| 登録レコードの所持金 | CBA1 + 人物番号×128 + 19h |
| 保存処理 | 0BF0から原作の保存処理へ。SRAMバンク0の登録先頭はA00A |
| 原作の金額表示 | 70D5→01A1でCAD9の金額を数値文字列化 |

PC・書込先・現在バンク・復帰先・命令列をすべて照合して、金額の作業RAMだけを倍率化します。ROMを書き換えず、ROM判別にハッシュも使いません。

配分対象の判定は原作のままです。外伝IIと同じく、経験値は状態値3未満、お金は状態値0に配られます。倍率化した値を原作の加算・表示・保存へ渡すため、所持残高全体や経験値にはお金倍率を掛けません。

## 検証

既存の外伝III勝利直前ステートで、経験値×1／×256それぞれと、お金の全7倍率×全5速度の計70組を確認しました。

- 経験値×1・等速では通常の獲得額が1人11。×8で88、×256で2,816。所持金100から×256で2,916になります。
- 同じ経験値・速度設定では、お金倍率を変えても倍率化前の抽選結果は一致。
- 6人分の登録レコードとSRAMの金額が一致。未参加の登録人物と所持金以外の項目は不変。
- 状態値1・3はお金を受け取らず、状態値1の経験値は加算される原作の条件を維持。
- 上限直前の所持金へ加算し、登録データ・SRAMとも4,294,967,295で停止。
- 倍率計算の上限、別バンク・別復帰先の拒否、ステート復帰後の設定保持を確認。

`gold_gaiden2_test` を外伝II・III共通の検証用に拡張し、CTestの `gold_gaiden3` として登録しました。検証用ステートは `GBWIZ_GAIDEN3_REWARD_CHECKPOINT` を使います。ROM・ステートは配布物に含めません。

Androidには `CoreTest.testGaiden3GoldRewards` を追加しました。全倍率のSRAM反映とリセット後の設定保持を検査しますが、今回の実機実行は未実施です。

助っ人枠を含む全パーティー構成、全敵・全宝箱・全状態の網羅検証ではありません。金額の基礎値は原作の乱数と処理時間で変化します。

外伝IIIのお金倍率追加後、既存を含むWindows CTest 33件が成功しました。Windows本体・Android本体（arm64-v8a / x86_64）・AndroidテストAPKもビルド済みです。
