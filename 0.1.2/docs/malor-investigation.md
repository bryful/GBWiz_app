# 外伝1 マロール制限解除の初期調査

2026-10-30追記: 更新されたAGENTS.mdに基づき、マロールを使わない自前マップと階層・位置移動を実装しました。[操作・実装・検証](dungeon-map.md)を参照してください。以下は以前のマロール調査記録です。

## 判断

「マップのどこでも使用可能・シナリオ制限も解除」という全面対応は、現段階ではコストが高いと判断し、追加解析・実装を保留します。
ユーザーから「コスト高いと判断した段階で相談」と指定されているため、この段階で相談します。アプリ・ROM・セーブの変更はしていません。

単一の相性判定を通過させる善悪混合とは異なり、移動先の選択範囲、特定値の除外、移動先の検査、移動後の処理を別々に確認する必要があります。
以下はローカルROMの命令列を読んだ初期調査であり、制限箇所をすべて特定した結果や、解除して実際に移動した検証ではありません。

## 確認した処理

| 箇所 | 静的に確認できた内容 | 未確認事項 |
|---|---|---|
| ROM 5C46〜、F8C2〜 | マロールの名称・使用区分と、移動中の呪文処理テーブルの対応。魔術師系の0始まり25番、呼出先7148 | 戦闘中の効果・使用制限との関係 |
| バンク3 7148〜 | 現在位置C8A5〜C8A7の退避、候補座標・階層の選択画面へ進む処理 | 各状態値とシナリオ進行の対応 |
| 71C5〜71FD | 階層値を増減し、下位7ビットを1〜6の範囲に戻す処理。上位ビットは保持 | この範囲外や上位ビットの意味、他マップを選択可能にした場合の扱い |
| 7287〜72B7 | 候補値86hの比較、候補座標を使う70B0の検査、C8B8での成功・失敗分岐 | 86hを除外する理由、座標検査を無視した場合の影響 |
| 70B0〜70C6 | マップ関連の5962・5B0Fを呼び、結果から可否を返す | 地形・マップ有効性・未探索等のどの条件を判定しているか |
| 72C7〜、732D〜 | 移動結果による分岐、座標の復元、マップ・画面の再構築、元のゲーム処理と保存への復帰 | 制限区域・特殊イベントへの進入時に必要な状態更新 |

アドレスは検証対象の外伝1のCPUアドレスを基本とし、ROMオフセットを明記した行だけファイル内位置です。ハッシュ判別は使用していません。

## コストが高い理由

- 禁止判定だけを外しても、移動先を選べる範囲や移動成立の条件は別に残ります。
- 除外の理由を確認せずに座標や階層の検査を通すと、原作のマップ読込やシナリオ状態と整合しない可能性があります。この影響は未検証です。
- 通常階層だけでなく、制限がある場所・特殊階層・シナリオ進行の異なる状態で検証する必要があります。現在確認済みの通常プレイ用ステートだけでは、全面解除の成立を示せません。

## 相談する選択肢

1. **いったん見送る（推奨）**：AGENTS.mdの「無理なら実装しない」に沿い、外伝1の仕上げと外伝2へ進む。必要性が出た時点で再検討する。
2. **対象を絞って再調査する**：解除したい具体的な場所・制限を決め、その前後の検証用状態を用意して該当判定だけを調べる。部分解除が低コストで可能とはまだ判断していない。
3. **全面解除の追加解析を続ける**：上記のマップ・進行状態を調べる作業を優先する。他の開発項目への着手はその分後になる。

その後、ユーザーからリリース準備と他作品への低コスト項目の展開を優先する指示を受けました。マロールの制限解除と追加の深掘りは保留しています。
