# 外伝1〜3／GBC Wizardry I〜IIIのMP消費なし（全体設定）

Androidは機能メニュー→サポート→「MP消費なし」、Windowsは機能メニューの「MP消費なし」で、左右操作によりON／OFFを切り替えます。Androidでは項目の左半分／右半分のタップでも切り替えられます。Aでは変更しません。初期値はOFFです。

キャラクター選択は不要です。ON中は全員に適用され、パーティーのメンバーを交代しても有効です。MP9固定と消費ゼロを比較し、原作の減算箇所だけを抑止できる消費ゼロ方式を採用しました。方式選択やキャラクター別の設定はありません。

## 動作

- 呪文使用時の現在MPが減らなくなります。町の呪文操作・移動中・戦闘中の減算箇所に対応します。
- MPの回復・補充はしません。現在MPが0の段階の呪文は、原作どおり使用できません。宿屋などで回復してください。
- 習得呪文、最大MP、職業、能力値、HP、所持品を変更しません。未習得の呪文を解禁する機能ではありません。
- 原作の回復処理や、イベント等によるMP変化は維持します。OFFにすると、その時点のMPから通常どおり消費します。
- 設定はsettings.iniの`no_mp_cost`へ保存し、次回起動・ROM切替・リセット後にも適用します。ステート読込では現在のON／OFFを維持し、MP値はステートの値を復元します。
- 未確認版・他作品では「対象外」としてONにできません。他作品へ切り替えても、対応作品で使う設定値は保持します。

従来のキャラクター別「現在MPを9にする」は操作画面から外しました。キャラクター別の操作は全呪文習得と属性変更です。

## 外伝1の方式

ROMヘッダーと、MP段階の参照処理・戦闘中の呪文番号から段階を引く処理・3箇所の減算命令列を照合します。ハッシュ判別やROMの書換えは行いません。

Gambatteの既存書き込みコールバックを報酬・作成ボーナス・倍速音声と共有し、作業用キャラクターのD145〜D152への減算だけを抑止します。対象はバンク2のPC=5386、バンク3のPC=6E85、バンク5のPC=4D41です。バンク・PC・アドレスに加えて減算値であることを確認します。原作のCPU進行・フラグ計算・キャラクター保存はそのまま使います。

## 外伝2への低コスト展開

外伝2の同じ3経路・同じ14段階の減算構造を照合し、アドレスを作品別プロファイルへ分離しました。現在MPは作業用D054〜D061、バンク判定はCFBD、減算PCはバンク2=4F8F／バンク3=70A8／バンク5=4D41です。全体設定・ON/OFF・保存設定の扱いは外伝1と同じです。
原作のMP段階参照・減算・保存命令を使ったWindows検証で、6人・全14段階・3経路・全速度と他項目の保持を確認しています。Android実機でも移動中の原作減算・保存、全6人・14段階・全速度、設定保持を確認しました。
テスト用データを使う原作処理の実行検証であり、外伝2の呪文を画面から選ぶ全場面の統合プレイや、通常セーブからの再起動の網羅検証ではありません。外伝3への追加対応は後述を参照してください。

## GBC Wizardry I〜III

既存の「MP消費なし」全体設定に対応しました。Windows／Androidとも同じ処理を使用します。初期値OFF、左右で切替、MP0からの補充なし、最大MP・習得呪文は変更しません。

人物レコードはC10Aから110バイト×20人、MPは+26h〜33hです。上位4ビットが現在MP、下位4ビットが最大MPで、原作の`SUB 10h; LD (HL),A`による書き込みだけを抑止します。ヘッダー、パーティ番号から人物を取得する処理、MP参照処理、4か所の減算命令列を照合します。ROM書換え・ハッシュ識別は使用しません。

| 作品 | MP参照（CPU） | 減算SUBの物理ROMオフセット（バンク4・4・6・7） |
|---|---|---|
| I | 25D4 | 105EF / 1283E / 1A2DF / 1CF33 |
| II | 25CC | 105F7 / 128FF / 1A37A / 1CF42 |
| III | 259A | 105EF / 12833 / 1A2EC / 1CF33 |

書込通知のPCはSUBのCPUアドレス+3です。C049のROMバンク、PC、人物MPアドレス、現在値から10hを引いた値であることを確認します。バンク6には僧侶系第2段階（レコード+2Eh）の残数を直接確認・消費する分岐もあります。回復、最大MP変更、人物転送・保存処理は対象外です。

`mp_color_test`は原作のMP参照・減算命令を実行し、6人、通常3経路の全14段階、直接参照経路の+2Eh、全5速度、OFF→ON→OFF、他人物・最大MP・他フィールドの保持、ステート読込後の設定維持、未確認命令列・別バンク・別PC・回復書込の除外を確認します。テスト専用ROMだけ減算後をRETにして入口を設けています。製品ROMは変更しません。

画面操作で全呪文を選択する統合プレイ、通常セーブ再起動の網羅確認は未実施です。検証用ROM・ステートは配布しません。

## 外伝3の3系統・4経路対応

外伝2の実装を再検証し、外伝3のMP消費なしを追加しました。魔術師・僧侶の作業用MPはCB60〜CB6D、錬金術師はCB8D〜CB93です。間の人物データは対象に含めません。初期値OFF、全体設定、MPの補充なしという操作は他作品と共通です。
