# GBWiz 0.1.2

2026-11-02のリリース版です。Windows x64とAndroid 8.0以降（arm64-v8a／x86_64）向けです。Androidは従来と同じGBWiz専用鍵で署名し、正式版0.1.0／0.1.1から上書き更新できます。既存の配布版は保持します。

## 0.1.1からの変更

- MP消費なしを外伝III・GBC版Wizardry I〜IIIへ追加。これでWizardry全6作品に対応します。
- 外伝IIIは錬金術師を含む全21段階、施設・戦闘・2か所の移動中減算に対応。
- GBC版I〜IIIは最大MPを維持し、現在MPだけの原作減算を抑止。
- 全体設定の左右操作でON／OFF。現在MPが0の段階は補充しません。
- 外伝IIの既存対応も再検証し、Pixel 9aで外伝II／IIIとGBC版I〜IIIの減算制御・メニュー操作を確認しました。

## 継続する機能

- 全6作品の自前マップと位置・階層移動。移動直前にスロット1へ保存。
- 外伝I〜III・GBC I〜III・DQ3の経験値／お金倍率。
- Wizardry全6作品の全呪文習得と現在／最大MP9、善悪混合、属性変更、作成ボーナス最大、ロゴスキップ。
- ROM選択・リセット、ROM名による通常セーブ、5スロット、NES配列のコントローラー、AB入替、タッチ操作、倍速＋主要な等速音声。
