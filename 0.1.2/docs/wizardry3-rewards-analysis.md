# GBC版Wizardry III：経験値・お金倍率の解析と実装

経験値とお金の倍率を、独立して×1／×8／×16／×32／×64／×128／×256から選べます。機能メニューの「獲得経験値」「獲得お金」を左右で変更します。原作の人数配分後の1人分に倍率を掛け、原作の表示・配分対象判定・加算・通常セーブへ渡します。

I・IIと同じ6バイトのビッグエンディアンpacked BCD形式です。III専用のアドレス・命令列・呼出元を確認し、BCDの倍率処理は3作品で共通化しています。ROMヘッダーと命令列で判別し、ハッシュやROMの書換は使用しません。

| 用途 | CPUアドレス・形式 |
|---|---|
| 経験値配分呼出 | ROMバンク1 6845: CALL 6F3A、復帰先6848 |
| 戦闘経験値総額 | WRAMバンク1 D47E〜D483 |
| 経験値の人数除算 | 6F5E: CALL 28C4、6F61: CALL 0E91 |
| 経験値倍率の適用 | HRAM FFBDへの最終書込後PC=6F88（書込命令6F85） |
| 戦闘から宝箱処理への呼出 | バンク1 688D〜6892からバンク6 5D68へfar call、復帰先6893 |
| お金の人数除算 | バンク6 5F7D: CALL 28C4、5F80: CALL 0E91 |
| お金倍率の適用 | FFBDへの最終書込後PC=5F8D（書込命令5F8C） |
| 1人分の作業領域 | HRAM FFB8〜FFBD、6バイトBCD |
| バンク確認 | C049=1（経験値）／6（お金）、FF70下位3ビット=1 |
| 人物の取得 | 2731：C103〜C108のパーティー番号から登録レコードを取得 |
| 人物レコード | 固定WRAM C10A + 人物番号×6Eh（110バイト） |
| 人物の経験値・所持金 | 経験値+17h〜1Ch、所持金+11h〜16h |
| 経験値の配分対象 | レコード+23hの状態値が4未満（6F97〜6F99） |
| お金の配分対象 | D543 + パーティー位置の戦闘状態値が2未満（5FA5〜5FA7） |
| BCD加算 | 経験値6FC0、お金5FBDから共通0DDBを呼出 |
| 通常セーブ | SRAMバンク0 A02B + 人物番号×6Eh |

経験値は復帰先6848を確認します。お金は保存AFの後にあるfar callフレームを読み、復帰先000F・呼出元ROMバンク1・復帰先6893を確認します。PC・書込先・ROM/WRAMバンク・呼出元が一致する配分額だけを変更し、別の呼出元、所持金全体、店や銀行の取引には倍率を掛けません。

倍率計算は64ビットで行い、原作の12桁上限999,999,999,999で止めます。BCDの各桁を検査し、不正な値には介入しません。人物への加算も原作のBCD飽和加算を利用します。

## 検証

コピーした既存の迷宮ステートから、原作の遭遇入口60A1へ入り、D139=1で遭遇を開始しました。戦闘と勝利は原作の操作入力で進め、経験値・お金の配分直前フレームをローカルfixtureとして保存しています。ROM・勝利結果・人物の経験値を直接作り替えたものではありません。

対象パーティーは登録番号0〜5の6人です。実戦闘を通した取得時は1人あたり経験値117、お金16でした。経験値直前から入力周期を揃えた検証では、お金の通常基礎額が15になります。原作の乱数と経過時間で基礎金額は変わるため、各条件で倍率化前の金額を記録して比較します。

- 経験値の全7倍率×全5速度（1／1.5／2／3／4倍速）。117が×8で936、×256で29,952として6人に加算され、SRAMにも反映。
- お金は経験値×1／×256と全7倍率×全5速度の70条件。等速・経験値×1では15が×8で120、×256で3,840として加算・保存。
- 同じ経験値・速度では、お金倍率を変えても原作の基礎金額が一致。
- 加算直後の対象項目以外の人物データ保持、全参加人物の通常セーブ反映を確認。
- 両倍率×1・等速の原作コア状態との完全一致。
- 経験値の状態値4の除外、お金の戦闘状態1の加算・2の除外を維持。
- 原作加算と倍率計算それぞれの12桁上限、所持金上限のSRAM保存を検査。
- 別バンク・別呼出元・不正BCD・未知の命令列の拒否、ステート復帰後の倍率保持を確認。

倍率による表示時間の変化で後続の宝箱・罠・入手アイテムなどが変わり得ます。直接の人物データ書換と区別するため、対象以外の項目の比較は加算直後に行っています。

I・II用のテストをI〜III共通に拡張し、CTestの `rewards_wizardry3` と `gold_wizardry3` として登録しました。CMakeの `GBWIZ_WIZARDRY3_REWARD_CHECKPOINT` と `GBWIZ_WIZARDRY3_GOLD_CHECKPOINT` にローカルの配分直前ステートを指定します。ROM・セーブ・検証用ステートは配布物に含めません。

Androidには `CoreTest.testWizardry3ExperienceRewards` と `testWizardry3GoldRewards` を追加しました。fixtureはアプリcache内の `wizardry3.gbc`、`wizardry3-before-experience.bin`、`wizardry3-before-gold.bin`。全倍率のSRAM反映とリセット後の設定保持を検査します。今回のAndroid実機実行は未実施です。全敵・全人数・全状態異常・全宝箱の組合せを網羅した検証ではありません。
