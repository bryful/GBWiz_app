# GBWiz 0.1.4

2026-11-15。Windows x64、Android 8.0以降（arm64-v8a／x86_64）向けです。

## 0.1.3からの変更

- 外伝I〜III・GBC版I〜IIIで、登録キャラクターの種族と職業を変更できます。外伝IIIは10種族・12職業、ほかの5作品は5種族・8職業に対応します。
- 対象キャラクターを選び、種族・職業の行を左右で変更します。Androidでは行の左右タップでも操作できます。変更は通常セーブに反映されます。

従来のマップ・移動、経験値／お金倍率、Wizardry支援、倍速、5スロットのステートセーブを継続します。
ソース・ROM・保存データ・秘密鍵・資格情報は同梱しません。操作はREADME.md、検証範囲はVALIDATION.mdを参照してください。
