# GBC版Wizardry II：経験値・お金倍率の解析と実装

経験値とお金を、それぞれ×1／×8／×16／×32／×64／×128／×256から選べます。原作が人数で割った1人分の配分額を倍率化し、表示・配分対象判定・人物への加算・通常セーブは原作の処理を利用します。操作は既存の機能メニューで左右変更です。

Iと同じ6バイトのビッグエンディアンpacked BCDを使用します。ただし処理アドレスと呼出元が異なるため、II専用のプロファイルと命令列確認を追加しています。ハッシュやROMの書換は使用しません。

| 用途 | CPUアドレス・形式 |
|---|---|
| 経験値配分の呼出 | ROMバンク1 69E3: CALL 70D4、復帰先69E6 |
| 戦闘経験値総額 | WRAMバンク1 D47E〜D483 |
| 経験値の人数除算 | 70F8: CALL 28F6、70FB: CALL 0E91 |
| 経験値倍率の適用 | HRAM FFBDへの最終書込後PC=7122（書込命令711F） |
| 戦闘から宝箱への呼出 | バンク1 6A2B〜6A30からバンク6 5E02へfar call、復帰先6A31 |
| お金の人数除算 | バンク6 6017: CALL 28F6、601A: CALL 0E91 |
| お金倍率の適用 | FFBDへの最終書込後PC=6027（書込命令6026） |
| 1人分の作業領域 | HRAM FFB8〜FFBD、6バイトBCD |
| バンク確認 | C049=1（経験値）／6（お金）、FF70下位3ビット=1 |
| 人物レコード | 固定WRAM C10A + 人物番号×6Eh（110バイト） |
| 人物の経験値 | レコード+17h〜1Ch |
| 人物の所持金 | レコード+11h〜16h |
| 人物の取得 | 2763：C103〜C108のパーティー番号から登録レコードを取得 |
| 経験値の対象 | レコード+23hの状態値が4未満（7131〜7133） |
| お金の対象 | D543 + パーティー位置の戦闘状態値が2未満（603F〜6041） |
| BCD加算 | 経験値715A、お金6057から共通0DDBを呼出 |
| 通常セーブ | SRAMバンク0 A02B + 人物番号×6Eh |

経験値は復帰先69E6を確認します。お金はSP上の保存AFを飛ばし、far call復帰先000F・呼出元バンク1・復帰先6A31のフレームを確認します。別の呼出元や別のバンク、不正なBCDには介入しません。人物の所持残高全体や店の取引には倍率を掛けません。

64ビットで倍率計算を行い、12桁の原作上限999,999,999,999で止めます。人物への加算も、原作のBCD飽和加算を使用します。

## 検証

既存の実戦闘中ステートから、原作の操作入力で勝利まで進めました。経験値・お金それぞれの配分直前フレームをローカルfixtureとして保存しています。ROM・勝利結果・人物の経験値を直接作り替えたものではありません。

対象パーティーの登録番号は0・1・2・4・5・6で、登録番号3は非参加です。6人の加算と保存に加えて、番号3の経験値・所持金が変化しないことを検査します。

- 経験値の基礎額は1人66。×8で528、×256で16,896を加算。全7倍率×全5速度（1／1.5／2／3／4倍速）を検証。
- お金は経験値×1／×256と全7倍率×全5速度の70条件で検証。経験値直前ステートから入力周期を揃えた等速・経験値×1では基礎額9、×8で72、×256で2,304を加算。
- 実戦闘を通して作ったお金直前ステートでは基礎額21。原作の乱数と経過時間で基礎額は変わるため、各条件で倍率化前の金額を記録して比較。
- 全参加人物の実加算・SRAM反映、非参加人物の非加算、加算直後の対象項目以外の人物データ保持を検査。
- 両倍率×1・等速で原作コアの状態と完全一致。
- 経験値の状態値4の除外、お金の戦闘状態1の加算・2の除外を維持。
- 経験値・所持金それぞれの原作加算と倍率計算の12桁上限、所持金のSRAMへの上限値保存を検査。
- 別バンク・別復帰先・不正BCD・未知の命令列の拒否、ステート復帰後の倍率保持を確認。

倍率による表示時間の変化で後続の宝箱・罠・入手アイテムなどが変わり得ます。その差と直接の人物データ書換を区別するため、対象以外の項目の比較は金額・経験値の加算直後に行います。

既存のI用テストをI／II共通の検証に拡張しました。CMakeの `GBWIZ_WIZARDRY2_REWARD_CHECKPOINT` と `GBWIZ_WIZARDRY2_GOLD_CHECKPOINT` を指定すると、CTestの `rewards_wizardry2` と `gold_wizardry2` として登録します。ROM・セーブ・検証用ステートは配布物に含めません。

Androidには `CoreTest.testWizardry2ExperienceRewards` と `testWizardry2GoldRewards` を追加しました。fixtureはアプリcache内の `wizardry2.gbc`、`wizardry2-before-experience.bin`、`wizardry2-before-gold.bin`。全倍率のSRAM反映とリセット後の設定保持を検査します。今回のAndroid実機実行は未実施です。全敵・全人数・全状態異常・全宝箱の組合せを網羅した検証ではありません。

検証結果：既存を含むWindows CTest全37件成功。Windows Release、Android Debug（arm64-v8a／x86_64）、AndroidテストAPKのビルドも成功しました。今回のAndroid実機操作は未実施です。
