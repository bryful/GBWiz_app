# ウィザードリィ共通 自前マップ・階層移動

## 対応作品

| 作品 | 選択できるマップ |
|---|---|
| GB 外伝I | 通常6階＋別領域6階 |
| GB 外伝II | 通常11階＋別領域1階 |
| GB 外伝III | ゲーム内マップ番号1〜36 |
| GBC I | 1〜10階。5〜7階は現在の進行フラグに対応する地形 |
| GBC II | 1〜11階 |
| GBC III | 1〜10階 |

ROMタイトルと対象命令列を確認した版に対応します。ROM判別にハッシュを使用せず、ROMファイルも変更しません。

## 操作

- Windows: M、コントローラー: RT / ZR、Android:「マップ」で開閉。
- Windowsの機能メニュー「迷宮マップ・移動」からも開けます。
- 矢印でXY、PageUp / PageDown（LB / RB）で階層・マップ番号を変更します。
- Aで決定して移動、Bでキャンセルして閉じます。WindowsのAはXまたはEnter、BはZです。
- Androidではマップ表示中の「LB / 階層↑」「RB / 階層↓」でも階層変更できます。
- 緑が現在地、黄色が選択位置。上が北、Xは東、Yは北に増加する0〜15の座標です。
- 白は壁、黄土色は扉、紫は隠し扉を含む特殊な壁種別です。

迷宮の移動待ち・キャンプのメニュー待ちで使用できます。街、戦闘、イベント、画面切替やキャラクター更新処理の途中では開けません。マップ表示中はゲームを一時停止します。

移動直前に必ず `<ROM名>.slot1.state` を保存します。選択中のスロット番号にかかわらずスロット1を上書きします。保存失敗時は移動しません。移動後はキャンプを閉じて通常の迷宮画面に戻ります。

## 実装

`src/dungeon_map.h` に作品別の地形読込・座標・入力待ち・再読込プロファイルを定義しています。表示と矢印・A/B・階層変更、保存前の検査はWindows / Androidで共通です。

| 作品 | X / Y / 階層のCPUアドレス | 通常再読込 |
|---|---|---|
| 外伝I | C8A5 / C8A6 / C8A7 | バンク3 409F |
| 外伝II | CC7A / CC7B / CC7C | バンク3 408D |
| 外伝III | C95F / C960 / C961 | バンク3 410D |
| GBC I〜III | C0F9 / C0FA / C0FC | バンク6 4492 |

- 外伝I・IIはROMバンク6の階層ポインタを読みます。外伝IIIはバンク30・31の連続地形領域を読みます。1セル2バイトで北から南の順です。
- GBC版はROMバンク63の地形を読みます。壁・イベントが別平面に分かれ、壁方向のビット配置も外伝と異なるため共通表示用に変換します。
- GBC Iの5〜7階はCA9Cの進行フラグから物理地形を選択します。フラグそのものは変更しません。
- バンクと実行中のスタックを照合して迷宮・キャンプの入力待ちだけを許可します。GBC版では戦闘モードも除外します。
- 保存成功後、コアのスナップショット内の座標を更新して通常の再読込へ戻し、地形・描画を再構築します。GBC版は原作のバンク呼出と同じ復帰フレームを用意してバンク2の入力待ちへ戻します。
- マロールの選択・可否判定・呪文消費・移動ルーチンは呼びません。
- 全方向が壁のセルと範囲外の座標には移動できません。
- Androidは保存キューの完了とスロット1の読み戻し一致、Windowsは一時ファイルからの書換完了を確認してから移動します。

基本地形を表示するため、開閉した扉やイベントで変化した一部の地形は表示に反映しません。シナリオフラグやイベントの達成状態を変更する機能ではありません。イベントマスへ直接移動したときの発火条件は通常歩行時と異なる場合があります。全イベント・全進行段階の組合せは未検証です。

## 検証

ローカルROM・既存プレイステートを利用する `map_test` と `map_all_test` で、6作品の計91マップを等速・4倍速で検証します。

- 各マップへの移動後180フレームの安定動作、入力待ちへの復帰、全256セルの地形と原作の読込結果の一致。
- 各作品で原作のB操作によりキャンプを開いてからマップを呼出・移動。移動後は通常の迷宮へ復帰。
- GBC Iの5〜7階について、進行フラグの各地形分岐と原作の地形読込結果の一致。
- 起動中・戦闘中・未知の再読込命令列の拒否、保存失敗時の状態保持、保存前に位置を変えないこと。
- スロット1相当のバックアップからの復帰、WRAM・通常セーブデータ・速度の復元。

既存を含むCTest 29件が成功。Windows ReleaseとAndroid Debug (arm64-v8a / x86_64) をビルドして確認しました。今回のAndroid実機UI操作は未実施です。

ROM・検証用ステートは配布物に含めません。
