# ゲーム別サポート

## ROM判別

ファイル名・拡張子・ハッシュには依存しません。
ROMヘッダーのGB/GBCフラグと内部タイトルから作品を判別します。

| 内部タイトル | 判別する作品 |
|---|---|
| WIZARDRY SOQ | 外伝1（GB） |
| WIZARDRY CAE | 外伝2（GB） |
| WIZARDRY SOD | 外伝3（GB） |
| WIZARDRY1 / WIZARDRY2 / WIZARDRY3 | Wizardry 1 / 2 / 3（GBC） |
| GBDQ3 | DQ3（GBC） |
| DQ1&2 | DQ1&2（GBC） |

内部タイトルが異なるROMはUnknownとして通常のエミュレーションを継続します。
この判別はゲーム固有処理の入口です。判別できる作品すべてにサポート機能が実装済みという意味ではありません。

## GB版・外伝1の起動ロゴスキップ

Android / WindowsでROM起動・ROM切り替え・リセット時に自動適用します。
機能メニューの「ロゴスキップ」でON／OFFできます。設定は保存され、次回のROM起動・リセットから反映します。
通常セーブを読み込んだ後、入力なしで起動フレームを高速実行し、タイトル演出の完了で止めます。
この間の映像・音声は出力しません。ROMやRAMへのパッチ、ボタン連打、事前ステートの流用は行いません。
手動のステート読込では起動処理を実行しません。

検出には、外伝1のタイトル用タイルマップ・文字タイル、LCDC・SCY・BGP、および描画の安定を使います。
演出中のタイル初期化を観測してからタイトルの安定を待つため、前段の権利表記で停止しません。
Gambatte既存のVRAM・ゼロページ参照APIだけで読み取り、エミュレータ内部は変更しません。

手元の外伝1では903フレーム（通常再生で約15秒）をスキップします。
固定フレーム数を終了条件にはしていません。別のコアで起動を検証し、成功時だけ切り替えます。
1,200フレーム以内に既知の描画状態を確認できない場合は、元のコアとその状態をそのまま保持して通常起動します。

## 検証

- 同じROM・同じ入力なし実行で、903フレームを通常実行した場合とCPU・RAM等のステートと画面が一致。
- ROMの末尾バイトを変更しても、ヘッダーによる作品判別が変わらないことを確認。
- GB/GBCと対象作品が合わない場合やUnknownの場合は、外伝1向けのスキップを適用しないことを確認。
- 起動コードを変更したテスト用メモリ上のROMで、検出失敗後も元のコア・VRAM・WRAM・IO・SRAMが変更されないことを確認。
- Androidでも起動時・リセット時の適用、SRAM保持、保存復元を検証。

GB版外伝1の[経験値・お金倍率](reward-support.md)を追加しました。命令列が一致する版でのみ有効です。
他作品の報酬倍率・MP操作・属性編集、およびマロール制限解除は未実装です。

外伝1では全体設定の[善悪混合パーティー](party-support.md)にも対応しています。
外伝2・3にも善悪混合のコア処理を追加し、各ROMの原作判定・ON／OFFをWindowsとAndroid実機で検証しています。他の追加サポートは[展開状況](porting-status.md)のとおり未実装です。
外伝2にはMP消費なしも追加しています。GBC Wizardry 1〜3は共通のタイトルメニュー検出によるロゴスキップを追加しました。その他の高コスト解析は、ユーザーの指定により保留しています。
外伝1では全体設定の[MP消費なし](mp-support.md)に対応しています。
外伝1では[全呪文習得](spell-support.md)にも対応しました。戦闘中を除き、登録キャラクターを選んでから操作画面で適用します。
