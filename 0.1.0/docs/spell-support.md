# 全呪文習得

外伝2・3にも対応しました。外伝2は全63呪文、外伝3は錬金術師系を含む全89呪文を習得し、現在MP・最大MPも全段階9にします。町・施設内でも使用できます。[外伝2・3の解析記録](gaiden23-spells-analysis.md)を参照してください。

GBC版Wizardry I・II・IIIに対応しています。町・施設内・迷宮・キャンプで対象の登録番号を選び、全呪文習得を実行すると、全54呪文の習得と同時に、魔術師系・僧侶系の全7段階の現在MP・最大MPを9にします。GBC版I〜IIIも登録番号とキャラクター名を表示します。ひらがな・カタカナ・英数字・記号に対応し、同名人物は登録番号で区別できます。属性変更は対象外です。詳しくは[Iの解析記録](wizardry1-spells-analysis.md)、[II・IIIの解析記録](wizardry23-spells-analysis.md)を参照してください。

## 外伝1

Androidでは機能メニュー→サポート→「キャラクターを選択」を開きます。
登録番号・名前から対象を選び、次の画面で「全呪文習得」を実行すると、魔術師系29・僧侶系32の全61呪文を習得し、現在MP・最大MPを全段階9にして、通常セーブへ保存します。
対象を選ぶだけでは適用しません。同名キャラクターは登録番号で区別できます。
Windowsでは機能メニューの「キャラクターサポート」から同じ順序で操作します。
操作画面の「対象を選び直す」またはBで対象一覧へ戻れます。

町の施設選択画面に加え、施設内・迷宮・キャンプでも登録済みキャラクターに実行できます。戦闘中は実行できません。
作成途中の未登録キャラクターは対象に含みません。
データ転送中や、ステート読込後の作業用データの対象を特定できない場合は適用を拒否します。
その場合はゲーム内のキャラクター操作を終えてから選び直してください。

HP・職業・レベル・能力値・経験値・お金・所持品は変更しません。呪文使用時の回数消費も通常どおりです。
全呪文習得時に現在MPも補充します。全体設定の[MP消費なし](mp-support.md)をONにしても、現在MPの回復は行いません。

## 方式

外伝1のROMヘッダー、呪文集計処理、レベル別呪文数テーブル、保存の検証値計算・複製処理の命令列を確認します。
ハッシュは使用しません。他作品や未確認の命令配置では有効化しません。
戦闘モードの値と、その設定命令列を確認して戦闘中を除外します。共有コピー処理の途中では適用しません。

登録キャラクターはWRAM D186から128バイトずつ並び、習得フラグは各レコード+39hから8バイトです。
1人目のD1BF～D1C6は、ユーザー提供の[外伝1の参考ページ](https://ds-cheat.boy.jp/gb/wizardrygaiden1.html)の呪文領域と一致しました。
MPは別領域の+41h～+4Ehです。魔術師系フラグの未使用上位3ビットは保持します。
参考URLは[作品別メモ](support-references.md)にも記録しています。

選択したキャラクターの登録WRAM、SRAMの本体・複製と、それぞれの検証値を更新します。
原作のキャラクター読込・保存処理から作業用データの対象も追跡し、選択対象ならその習得フラグも更新します。
これにより、施設操作を続けた後も習得が消えず、作業中のHPなどを保持します。MPは14段階すべて9にします。
原作の検証値は隣接する2バイトを1バイトずつずらして加算する16ビット値です。
他キャラクターや他の保存項目は変更しません。ROMの書き換えや常時強制するコードは使いません。
アプリ側では適用前の保存を完了させてから編集し、既存の通常セーブ保存経路で書き出します。
書き出し時の通常セーブの`.bak`作成は従来どおりです。

一度きりの習得操作で、継続ON設定ではありません。以前のステートを読むと、その時点の習得状態へ戻ります。
適用後のファイル保存に失敗した場合は、メモリーには適用済みであることを表示し、再保存を促します。

## 検証

`spell_test`は6人の登録キャラクターを順に対象とし、名前の復号、全61呪文のフラグ、
現在MP9・他の登録項目・他の保存領域の維持、本体と複製の検証値、再適用時に変化しないことを確認します。
保存データだけを別のコアへ渡し、原作の起動処理を通した後も習得とMP9が残ることを検証します。
使い捨ての別コアでは原作の呪文集計処理も実行し、レベル別に全61呪文として認識されることを確認しています。
ステート読込で元の状態へ戻ること、空欄・範囲外・戦闘中・未確認版を拒否することも検証します。

```powershell
.\build\Release\spell_test.exe .rom/wizardrygaiden1.gb build/bonus/city/core.bin
```

CTestへの登録は`GBWIZ_SPELL_CHECKPOINT`に町の施設選択画面のローカルステートを指定します。
Androidの`CoreTest.testGaiden1Spells`も同じステートをcache内の`gaiden1-town.bin`として使用します。
ROM・セーブ・ステートは配布物に含めません。
全呪文を全場面で実際に唱える網羅テストではありません。
`spell_context_test`では町・施設内・作成画面・迷宮・キャンプの5場面で6人ずつ適用し、
他キャラクター・HP・他項目の維持と、操作再開後も習得が残ることを確認します。
戦闘中の拒否、原作の作業データ保存後の維持、同名キャラクターの区別も検証します。
CTestの`GBWIZ_SPELL_CONTEXT_ROOT`にはこれらのローカルステートを含むbuildフォルダを指定します。
Androidにも場面別のコア検証、対象選択だけでは適用されないこと、戦闘中の拒否を確認するテストを追加しています。
今回のAndroid版はビルド済みですが、実機が未接続のため、新しい操作経路の実機検証・インストールは未完了です。

2026-10-29にWindowsの全17テストが成功しました。Androidのアプリ・テストAPKもビルド成功しています。
