# 外伝1のキャラクター属性変更

Androidは機能メニュー→サポート→「キャラクターを選択」、Windowsは機能メニュー→「キャラクターサポート」から対象を選びます。
「属性を善にする」「属性を中立にする」「属性を悪にする」を選び、A／Enterまたは項目のタップで実行します。
対象を選ぶだけ、上下移動、左右操作では変更しません。

登録済みの選択キャラクターだけを変更します。職業・能力値・HP・MP・習得呪文・所持品・他キャラクターは維持します。
善悪混合パーティーを可能にする設定とは別の機能です。原作の編成制限や職業条件を解除するものではありません。
戦闘中・データ転送中・作業中の対象が特定できない状態では実行できません。

通常セーブにも反映し、ゲーム操作を続けた後や再起動後も維持します。以前のステートを読むと、その時点の属性へ戻ります。
原作のイベントによる属性変化は通常どおりです。属性を常時固定する機能ではありません。
適用前に通常セーブの保存を完了させ、適用後も保存します。適用後の保存に失敗した場合は、変更済みであることと再保存が必要であることを表示します。

## 方式

ROMヘッダーと既存のキャラクター読込・保存処理に加え、属性選択の格納処理、表示処理、善・中立・悪の文字列と参照テーブル、パーティー属性の更新処理を照合します。ハッシュは使用しません。
未確認の版や他作品には適用しません。

登録レコードはD186から128バイト単位、属性はレコード+0Ah（善=0、中立=1、悪=2）。作業用キャラクターではD10Eです。
既存の対象追跡・編集処理を再利用し、登録WRAM、選択対象の作業データ、SRAMの本体と複製・検証値を更新します。
パーティーのC950以降にも属性が上位2ビットに記録されるため、選択対象の項目だけを更新し、下位の登録番号・状態ビットを維持します。

## 検証

Windowsの`alignment_test`は次を検証します。

- 町・施設内・作成画面・迷宮・キャンプの5場面、登録6人、全3属性。
- 他項目・他キャラクターの維持、パーティーの属性記録、本体・複製・検証値。
- 操作再開後と通常セーブから再起動した後の維持、ステートによる元の属性の復元。
- 原作のキャラクター読込・保存処理を通した維持、作業中のHPの保持、同名キャラの区別。
- 再実行、不正な属性・空欄・範囲外・戦闘中・未確認版の拒否。

Androidにも全属性・保存再起動・対象選択後の実行・戦闘中の拒否・縦横の直接タップの検証を追加しています。
検証用ROM・セーブ・ステートは配布物に含めません。

2026-10-29：Windows Releaseビルドと全19テストが成功。Android ARM64／x86_64のアプリ・テストAPKもビルド成功しました。
Pixel 9aでは属性変更、GB／GBCコア、キャラクター操作2件、描画・タップ4件の計8テストが成功し、縦横メニューの画像も確認しました。開発APKを実機へ更新済みです。

実機検証中に、操作をせず繰り返しステート保存した場合でも、対象外マッパーの未設定項目が変動する既存コアの問題を確認しました。
Gambatteのステート保存・サイズ算出用構造体をゼロ初期化する修正を加え、GB／GBCの連続保存の一致と既存の保存・復元を回帰検証しています。
