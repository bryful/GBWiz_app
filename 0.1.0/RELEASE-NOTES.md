# GBWiz 0.1.0

2026-10-31のリリース版です。Windows x64とAndroid 8.0以降（arm64-v8a／x86_64）向けです。AndroidはGBWiz専用鍵による署名済みrelease APKです。過去のrc1〜rc4は保持しています。

## rc4以降の追加

- GBC版DQ3の戦闘経験値・獲得金倍率。×1／×8／×16／×32／×64／×128／×256を独立設定し、人数配分、職業別経験値上限、所持金上限、商人の追加獲得処理を維持します。
- 外伝II・IIIとGBC版Wizardry I〜IIIの作成ボーナス最大。外伝I〜IIIは30、GBC版は60ポイント。原作の種族・性別補正と能力上限、振り分け・払戻し・登録・保存を維持します。

## 収録する主な機能

- 全6作品の自前マップと位置・階層移動。移動直前にスロット1へ保存。
- 外伝I〜III・GBC版I〜III・DQ3の経験値／お金倍率。
- 外伝I〜III・GBC版I〜IIIの全呪文習得と現在／最大MP9、善悪混合、作成ボーナス最大。
- GBC版の人物名表示、メニューの文字サイズ固定。
- ROM選択・リセット、ROM名に基づく通常セーブ、5スロット、NES配列のコントローラー、AB入替、タッチ操作、倍速＋主要な等速音声。

ソースコードは別途配布し、このパッケージへ同梱しません。ROM・セーブ・ステート・秘密鍵・パスワードも含めません。検証結果はVALIDATION.md、使用方法はREADME.mdを参照してください。
