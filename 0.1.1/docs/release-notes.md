# GBWiz 0.1.1

2026-11-01のリリース版です。Windows x64とAndroid 8.0以降（arm64-v8a／x86_64）向けです。Androidは従来と同じGBWiz専用鍵で署名し、正式版0.1.0から上書き更新できます。既存の0.1.0配布物は保持します。

## 0.1.0からの変更

- Wizardry対象6作品（外伝I〜III・GBC I〜III）の属性変更に対応。対象人物の「属性 ‹ 善／中立／悪 ›」を左右で変更・保存します。Androidは行の左右タップにも対応し、Aでは属性を変更しません。
- 外伝II・IIIのロゴスキップを追加。これでWizardry対象6作品すべての起動・ROM切替・リセット時に対応します。固定フレーム数ではなく完成したタイトルの描画を検出し、確認できない版は通常起動します。
- 通常の成功通知を整理し、エラーをゲーム画面・操作領域の外の専用欄へ表示します。

## 継続する機能

- 全6作品の自前マップと位置・階層移動。移動直前にスロット1へ保存。
- 外伝I〜III・GBC I〜III・DQ3の経験値／お金倍率。
- Wizardry全6作品の全呪文習得と現在／最大MP9、善悪混合、作成ボーナス最大。
- MP消費なしは外伝I・II。
- ROM選択・リセット、ROM名による通常セーブ、5スロット、NES配列のコントローラー、AB入替、タッチ操作、倍速＋主要な等速音声。
