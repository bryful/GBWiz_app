# 外伝III：起動ロゴスキップ

2026-11-01。Windows／Androidの既存「ロゴスキップ」設定で、外伝IIIのメーカー表示・タイトルの変形／スクロール演出を省略します。起動・ROM切替・リセットへ適用し、設定OFFでは通常起動します。ステート読込では起動処理を実行しません。

## 解析

入力なしの起動をフレームごとに採取し、画面・VRAM・表示レジスターを確認しました。外伝IIIは外伝IIと異なり、符号付きタイルを使用し、SCY=E8（-24）の位置で完成したタイトル・副題・案内文を表示します。画面が安定しただけではメーカー表示などで誤判定するため、次の条件を組み合わせます。

| 判定 | 内容 |
|---|---|
| 作品 | GB外伝IIIのROMヘッダー。ハッシュは使用しない |
| 表示設定 | LCDC=81、SCY=E8、SCX=0、BGP=E4 |
| 副題 | BGマップ9800の6行目＋5列の確認済み配置 |
| 案内文 | 同11行目、13行目＋4列の確認済み配置 |
| 字形 | 符号付きタイル51のS（VRAM9510）と4EのW（94E0）の16バイトを照合 |
| 演出完了 | タイトル描画への遷移を観測した後、完成画面が8フレーム以上安定 |

原作のタイトル制御はROMバンク0Fにあり、402B〜4060がスクロール位置をE8へ進め、タイトル文字表示後に40ABから4277の待機処理を呼びます。4277〜42A3は入力を監視し、入力を検出すると2053へ進んでボタン解放を待ちます。入力確認テストもAの押下と解放を行います。

手元のROMでは新規／不正セーブ内容で787フレーム、有効な既存セーブありで726フレーム（約12〜13秒）を省略しました。固定フレーム数を終了条件には使用しません。

## 実装

`game_support.h` の既存ロゴスキップに `gaiden3TitleReady` を追加しました。別の新規コアへ通常セーブをコピーして入力なしで起動し、描画条件を確認できた場合だけ実行中コアを置き換えます。途中の映像・音声は出力しません。ROM／RAMのパッチ、合成したボタン入力、事前ステートは使いません。

1,200フレーム以内に検出できなければ、元のコアと表示内容を保持して通常起動します。Androidも音声ドライバーの対応判定から独立して外伝IIIの起動ROMを保持し、起動とリセットに使用します。

## 検証範囲

外伝IIの起動テストを作品別の描画判定と通常起動処理へ対応させ、外伝IIIでも実行します。初期・擬似的な不正・実際の人物登録済みセーブの3条件で、同じフレーム数を進めた通常起動の全コア状態・画面との一致を確認します。Aを押して離した後の状態・画面遷移も比較します。

有効なセーブから起動した場合、原作自身がSRAMバンク3のA078〜A07D（保存データの6078〜607D）の6バイトをFFへ変更することを確認しました。この原作動作を維持し、それ以外の保存データが変わらないことを検査します。スキップ側で保存データの修正・初期化は行いません。

副題・案内文・末尾行・字形・表示設定を個別に壊した場合、前段の演出、未知の起動処理、Unknown作品を誤検出しないことも確認します。検証用ROM・ステート・セーブは配布しません。

## 検証結果

Windows Releaseビルド成功。外伝IIIの新規起動チェックと既存ロゴスキップ・倍速・保存・善悪混合等を含む関連CTest全29件が成功しました。倍速テストは、ロゴスキップ成功時に旧来の起動待ち800フレームを追加しないよう調整し、完成したタイトルからBGM・入力を比較します。

Android Debugのarm64-v8a／x86_64とテストAPKのビルド成功。接続端末では外伝II／III・GBC I〜IIIのロゴスキップ、既存外伝1の設定切替、人物操作を含む計13件が成功しました。外伝IIIについてセーブなし／有効セーブありの通常起動との状態一致、原作動作を含む保存保持、リセット、OFF→ON、ステート読込、未知の起動処理でのフォールバックを確認しました。

既存の正式署名アプリと保存データを保持し、検証専用ID `jp.gbwiz.alignmentcheck` のみ更新しました。
