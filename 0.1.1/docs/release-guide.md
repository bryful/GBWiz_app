# GBWiz 0.1.1 リリース版

2026-11-01時点の機能をまとめたリリース版です。Android APKはGBWiz専用鍵で署名しています。

## Windows

Windows ZIPをすべて展開し、Windowsフォルダ内のGBWiz.exeを起動してください。SDL2.dllを同じ場所に置きます。初期ROMフォルダは実行ファイル横のRomです。ROMは付属しません。

通常セーブ・設定・ステートは `%APPDATA%\GBWiz` にROMファイル名で保存します。更新前にこのフォルダをバックアップしてください。以前の通常セーブを使う場合はROMファイル名を維持します。

| 操作 | キーボード | コントローラー |
|---|---|---|
| 移動・項目選択 | 矢印 | 十字キー |
| A／B | X／Z | NES配列の右／下のフェイスボタン |
| Start／Select | Enter／右Shift | Start／Select（＋／−） |
| 機能メニュー | F1／Esc | 左スティック押し込み |
| スロット1保存／読込 | F5／F8 | LT／右スティック押し込み |
| 迷宮マップ | M | RT／ZR |

速度・倍率・ON／OFFは項目を選び、左右で変更します。A・B配置は設定で入替可能です。リセットは選択すると即実行します。

## 自前マップと移動

外伝I〜III・GBC版I〜IIIの全6作品で使用できます。迷宮内・キャンプ中に呼び出せます。戦闘中は使用できません。

- 矢印で移動先のXYを指定。
- PageUp／PageDown、LB／RBで階層を変更。
- Aで移動を決定、Bでキャンセル。
- 移動実行の直前に、必ずステートスロット1へ保存します。保存に失敗すると移動しません。

原作のマロールを使わず位置・階層を変更し、原作の地形読込へ戻します。スロット1は移動前の状態で上書きされます。基本地形を表示するため、開閉した扉や一部のイベント変化は表示に反映しません。直接移動した際のイベント発火は通常歩行と異なる場合があります。

## 経験値・お金倍率

外伝I〜III・GBC版I〜III・GBC版DQ3の全7作品で、それぞれ ×1／×8／×16／×32／×64／×128／×256 を独立設定・併用できます。原作の人数配分後の1人分へ適用し、原作の対象判定・加算・表示・通常セーブを利用します。既存の所持残高全体を増やす機能ではありません。

外伝は32ビット上限、GBC版Wizardryは12桁BCDの原作上限で止めます。DQ3は経験値の職業別上限と所持金999,999を維持し、商人の追加獲得分にもお金倍率を適用します。設定は再起動・リセット後も維持し、ステート読込でも現在の設定を保持します。表示時間が変わるため、後続の乱数結果が変わる場合があります。

## その他の支援機能

| 機能 | 対応作品 |
|---|---|
| 作成ボーナス最大 | 外伝I〜IIIは30、GBC版I〜IIIは60ポイント |
| 全呪文習得・現在MP／最大MPを9に設定 | 外伝I〜III・GBC版I〜III |
| 人物の属性変更 | 外伝I〜III・GBC版I〜III |
| MP消費なし | 外伝I・II |
| 善悪混合パーティー | 外伝I〜III・GBC版I〜III |
| メーカーロゴのスキップ | 外伝I〜III・GBC版I〜III |
| 1.5／2／3／4倍速、主要なBGM／SEの等速再生 | 全6作品とGBC版DQ3 |

属性は対象人物を選び、「属性 ‹ 善／中立／悪 ›」の左右操作で変更・保存します。Androidは項目の左右タップにも対応し、Aでは変更しません。

全呪文習得は戦闘中以外で対象人物を選んで実行します。GBC版の一覧には登録番号と名前を表示します。善悪混合は属性を変更せず加入制限を切り替え、OFFでも既存パーティーは解散しません。GBC版の候補一覧表示中にONにした場合は、Bで戻って一覧を開き直してください。

未知のROM版には個別サポートを適用しません。ROM判別や保存名にハッシュを使用しません。DQ1＆2は対象外です。

## Android

Android 8.0以降、arm64-v8a／x86_64向けです。タッチボタン・コントローラーで操作できます。

`Android/GBWiz-0.1.1.apk`を端末へコピーしてインストールします。GBWiz専用鍵で署名済みの非debuggable版です。確認用開発APKや未署名APKはこの配布物へ同梱していません。

旧開発版は署名が異なるため上書き更新できません。移行する場合はDocuments/GBWizをバックアップし、開発版を削除してから正式版をインストールしてください。起動後に既存のGBWiz保存フォルダを選べます。0.1.0正式版からは同じ署名による上書き更新が可能です。今回の配布準備で既存アプリやユーザーデータの削除は行いません。

現在のAndroid初期ROMフォルダはDocuments/GBWiz/romで、任意フォルダを選択できます。AGENTS.md指定のDocuments/NesDQとの整合は残件です。設定・通常セーブ・ステートは選択したDocuments/GBWiz配下に保存します。

DQ3の報酬倍率、全6作品の作成ボーナスなどはPixel 9aのJNI経由で実機検証しています。操作した画面・条件の詳細はVALIDATION.mdと各機能の解析資料を参照してください。全イベント・長時間プレイ・実物コントローラーの網羅確認は行っていません。
