# 外伝II・III：キャラクター属性変更

2026-11-01。外伝II・IIIもキャラクターサポートの「属性 ‹ 善／中立／悪 ›」を左右で変更できます。Androidは行の左右タップでも変更します。Aでは属性を変更しません。変更は通常セーブにも反映します。

## 作品別の格納と照合

| 項目 | 外伝II | 外伝III |
|---|---|---|
| 登録人物のWRAM先頭 | D095 | CBA1 |

各人物は128バイト、属性はレコード＋0Aに善0／中立1／悪2を格納します。GBC版のようなビット共有ではなく、外伝1と同様の独立した値です。文字列の並びと作成時の選択結果、パーティー更新処理の参照を照合しました。ROMのハッシュは使用しません。人物保存・バックアップ・作成選択・表示・パーティー更新の命令列が未確認の版では属性編集を有効にしません。

## 実装

既存の全呪文習得の人物編集経路を共通化しました。登録WRAM・SRAM本体と、対象人物に対応する施設内作業データの属性だけを変更し、SRAMの人物バックアップと検証値を更新します。検証値は隣接2バイトずつの16ビット加算です。未保存のHP等や他人物のデータを保持します。

パーティー欄は上位2ビットにも属性を持つため、対象人物と一致する参加枠だけを更新します。下位6ビット、空欄、他人物、人数は保持します。通常セーブの保存経路は既存の処理を使います。

戦闘・転送中・空欄・範囲外・保存側と人物が不一致・同名で作業人物を特定できない場合は拒否します。以前のステートを読むと属性もその時点へ戻ります。職業・善悪混合設定・原作の属性変化イベントの条件は変更しません。

## 検証

`alignment_gaiden23_test` は各作品の既存プレイ状態・町の施設選択・施設内の3状態を使用します。全登録人物×3属性について、他項目・他人物・パーティー欄の保持、人物バックアップと検証値、反復適用の同一性、通常セーブだけを渡した別コアの通常起動、ステートによる元の属性復元を確認します。

原作の人物読込・保存命令を直接実行する専用コアでも、作業中の人物への属性変更が保存後に維持され、未保存HPが保持されることを確認します。別人物を編集したときは作業データを変更しません。戦闘・割込で中断された転送・空欄・別人物・同名で特定不能な作業データ・未確認版も拒否します。

製品側で原作の命令やROMファイルを書き換える方式ではありません。検証用ROM・ステート・セーブは配布しません。全イベントを通した長時間プレイと、今回のタッチ操作の縦横確認は網羅検証に含めません。

Android Debug（arm64-v8a／x86_64）とテストAPKのビルドが成功しました。接続端末のCharacterFlowTest全9件も成功しています。外伝II・IIIの対象選択・Aで非変更・左右の循環・表示値・他のセーブ領域保持を含みます。既存の正式署名アプリと保存データを保持し、検証用ID `jp.gbwiz.alignmentcheck` だけを更新しました。

最終確認：Windows Releaseビルドと関連CTest全58件が成功しました。新規6件に加えて外伝1・GBC I〜IIIの属性変更、6作品の呪文編集、善悪混合、保存等を含みます。
