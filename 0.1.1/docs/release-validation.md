# GBWiz 0.1.1 検証結果

2026-11-01。Windows x64 ReleaseとAndroid release APKを対象にまとめています。

## 確認済み

- Windows Releaseビルド成功、CTest全99件成功。対象7作品のコア、保存・復元、自前マップ、報酬、呪文・属性、作成ボーナス、善悪混合、MP、倍速音声、ロゴスキップ等を含みます。
- Android releaseビルド成功。applicationIdはjp.gbwiz、versionCode 7、versionName 0.1.1、非debuggable、最小SDK26、arm64-v8a／x86_64を確認。
- Android lintRelease成功（0 errors、11 warnings）。権限定数の指摘2件を修正。残る警告はアイコン、バックアップ設定、開発用ビューのコンストラクター、タッチビューのアクセシビリティ等に関するものです。
- APK署名v2／v3の検証成功。従来の0.1.0と同じGBWiz証明書です。
- APKの16KBページ整列、両ABIのELF LOADセグメントの16KB整列を確認。
- 最終コードのAndroid実機テスト14件成功。外伝II／IIIとGBC I〜IIIのロゴスキップ、外伝1の設定切替、対象6作品の属性操作・人物操作、フォルダ保存を含みます。実機検証は専用ID jp.gbwiz.alignmentcheck のDebug版で行い、既存の正式版とその保存データは維持しています。

- 配布フォルダのWindows EXEで対象7作品のスモーク実行が成功。各180フレームの映像変化とステート保存復元を確認し、ユーザーの保存データには触れません。
- 配布物とWindows ZIPに、ソース・ROM・セーブ・ステート・秘密鍵・開発APK・未署名APKが含まれないことを確認。配布EXE／APKが検証済みバイナリーと一致し、SHA256SUMSを照合しました。

## 残る確認・既知の制限

- この署名済みrelease APKそのものの端末へのインストール・起動確認は今回行っていません。同じコードのDebug版で上記実機テストを実施しました。
- 全イベント・全進行段階・長時間プレイ、実物Xbox／Proコントローラーの網羅検証は未完了です。
- Androidの初期ROM場所はDocuments/GBWiz/romです。指定Documents/NesDQとの整合は残件です。任意のROMフォルダを選択できます。
- MP消費なしは外伝I・IIが対象です。外伝IIIとGBC I〜III、DQ3の任意支援は未対応です。
- 自前マップには一部の地形変化が反映されず、直接移動した際のイベント発火は通常歩行と異なる場合があります。
- 過去のステートを読むと人物編集もその時点へ戻ります。通常のゲーム内セーブを併用してください。

細かい検証条件はdocs内の各解析・機能記録を参照してください。0.1.0配布フォルダは保持し、外部への公開・アップロードは行っていません。
