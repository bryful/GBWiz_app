# 外伝II：起動ロゴスキップ

2026-11-01。Windows／Androidの既存「ロゴスキップ」設定で、外伝IIのメーカー表示・風景演出・タイトルのスクロール演出を省略します。ON／OFF設定は共通の既存設定を使用し、次のROM起動・切替・リセットから反映します。ステート読込では起動処理を実行しません。

## 解析結果

入力なしで起動した画面とVRAM・表示レジスターを時系列で採取しました。メーカー表示の後に風景演出があり、暗転を挟んでタイトルがスクロールします。スクロール後に副題と案内文が表示され、入力待ちになります。風景演出にも画面がしばらく静止する区間があるため、画面の安定だけでは判定できません。

終了条件は次のすべてを確認します。

- GB版外伝IIのROMヘッダー。ハッシュは使用しません。
- LCDC=93、SCY=0、SCX=0、BGP=E4。
- BGマップ9800の9行目＋4列の副題先頭、14行目の案内文、16行目＋4列の末尾行が、それぞれ確認済みのタイル配置であること。
- タイル44のCと54のWについて、番号だけでなく16バイトの字形も一致すること。
- 描画の遷移を観測した後、完成した画面が8フレーム以上安定していること。

手元のROMでは通常セーブなし・不正なセーブ内容で977フレーム、有効な既存セーブありで938フレームを省略しました（約16秒）。これは観測結果であり、フレーム数を終了条件には使用しません。セーブが無効な場合の初期化は原作の処理が行い、スキップ側でセーブ内容を初期化・修正しません。

## 実装

`game_support.h` に `gaiden2TitleReady` を追加し、既存の `skipBootLogos` に外伝IIを登録しました。別の新規コアに通常セーブをコピーして、入力なしの起動フレームを映像・音声出力なしで実行します。確認できた場合だけ実行中コアを置き換えます。ROM／RAMへのパッチ、合成したボタン入力、事前ステートは使いません。

1,200フレーム以内に確認できなければ、元のコアと映像をそのまま維持して通常起動します。Androidは音声ドライバーの対応判定とは独立に外伝IIの起動ROMを保持し、ロゴスキップとリセットに利用します。

## 検証

`gaiden2_boot_test` では初期セーブ・擬似的な不正セーブ・実際の人物登録済みセーブの3条件で、スキップ後と同じ時間だけ入力なしで進めた通常起動の全コア状態・映像が一致することを検証します。有効な通常セーブの保持と、その後のA入力による画面遷移・コア状態の一致も確認します。

副題・案内文・末尾行・字形・表示レジスターを個別に壊した場合の拒否、前段の演出で停止しないこと、起動処理を確認できない版やUnknown作品で元のコア・画面を変更しないことも検証します。検証用ROM・ステート・セーブは配布しません。

## 検証結果

Windows Releaseビルド成功。外伝IIの新規テストと既存ロゴスキップ・倍速・善悪混合・ROM切替／保存等を含む関連CTest全28件が成功しました。

Android Debugのarm64-v8a／x86_64とテストAPKのビルド成功。接続端末ではCoreTestの外伝IIロゴ・GBC I〜IIIロゴ・既存外伝1切替の3件と、CharacterFlowTestの人物操作9件の計12件が成功しました。外伝IIはセーブなし／有効なセーブありで通常起動との状態一致、リセット、設定OFF→ON、ステート読込後の保存保持、未知の起動処理のフォールバックを確認しました。

実機は既存の正式署名アプリと保存データを保持し、検証専用ID `jp.gbwiz.alignmentcheck` のみ更新しました。
