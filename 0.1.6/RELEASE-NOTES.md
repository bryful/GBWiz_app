# GBWiz 0.1.6

2026-11-21。Windows x64、Android 8.0以降（arm64-v8a／x86_64）向けです。

## 0.1.5からの変更

- 外伝I〜III・GBC版I〜IIIの酒場・商店・キャンプで使える、パーティーのアイテム編集を追加しました。
- 左右２人の所持品表示、装備・解除、受け渡し、削除、並べ替えに対応しました。
- 未識別品の収集と未装備品の一括移動を追加しました。空き枠と呪いを考慮し、識別状態などを保持します。
- アイテム変更後は原作処理で能力を再計算し、通常セーブとチェックサムを更新します。
- GBC版の漢字表示命令を解析し、アイテム名を原作フォントで日本語表示するようにしました。
- Androidは既存のタッチキーパッドを使い、左右の人物選択ボタンもタッチ操作できます。

従来のキャラクター編集、踏破マップ、マップ移動、支援機能、倍速、ステートセーブを継続します。
ソース・ROM・保存データ・秘密鍵・資格情報は同梱しません。操作はREADME.md、検証範囲はVALIDATION.mdを参照してください。
