# GBWiz 0.1.7

2026-11-21。Windows x64、Android 8.0以降（arm64-v8a／x86_64）向けです。

## 0.1.6からの変更

- 外伝Iの商店などでアイテム編集が開けない問題を修正しました。
- 場所ごとの制限を撤廃し、１人以上のパーティーがいれば、迷宮・町外れ・キャッスル・商店・訓練所などで開けるようにしました。戦闘中・データ転送中は除外します。
- Androidのマップボタンの下に「アイテム」ボタンを追加しました。もう一度押すとゲームに戻ります。
- 縦横画面で追加ボタンと既存操作ボタンが重ならないよう配置を調整しました。

従来のアイテム編集・日本語名表示・各種支援機能を継続します。
ソース・ROM・保存データ・秘密鍵・資格情報は同梱しません。
