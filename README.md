# GBWiz

ゲームボーイ／ゲームボーイカラーの『ウィザードリィ』『ドラゴンクエストIII』を、快適に遊ぶためのエミュレーターです。倍速プレイやステートセーブに加え、作品に応じたプレイ支援機能を備えています。

**現在の配布版は 0.1.0-rc2（リリース候補）です。**

## ダウンロード・起動方法

### Windows

1. [Windows版 ZIP をダウンロード](./0.1.0-rc2/GBWiz-0.1.0-rc2-Windows.zip?raw=true)します。
2. ZIPをすべて展開し、`GBWiz.exe`を起動します。`SDL2.dll`は同じフォルダーに置いてください。
3. 遊びたいGB／GBCのROMファイルを選択します。実行ファイルと同じ場所にある`Rom`フォルダーに入れておくと選びやすくなります。

ゲームのROMは付属しません。ご自身で用意したROMファイルが必要です。

### Android

Android版のインストール用パッケージは準備中です。現在フォルダー内にある`unsigned.apk`は未署名のため、そのままインストールして遊ぶことはできません。

## 主な機能

- **倍速プレイ**：1.5倍・2倍・3倍・4倍。主要な場面ではBGM・効果音を通常速度で再生します。
- **ステートセーブ**：5スロットに保存。スロット1はショートカットで保存・読込できます。
- **プレイ支援**：経験値・お金の倍率変更、MP消費なしなど。利用できる項目は作品によって異なります。
- **コントローラー操作**：Xboxコントローラー／Proコントローラーに対応。A・Bの入れ替えもできます。
- **機能メニュー**：プレイ中にROMの選択やリセット、速度・支援機能の変更ができます。

## 対象作品

| 作品 | プレイ支援の対応状況 |
| --- | --- |
| ウィザードリィ外伝I | 経験値・お金の倍率、キャラクター作成時のボーナス最大、MP消費なし、善悪混合パーティー、ロゴスキップ、全呪文習得・属性変更 |
| ウィザードリィ外伝II | MP消費なし、善悪混合パーティー |
| ウィザードリィ外伝III | 善悪混合パーティー |
| ウィザードリィI・II・III（GBC版） | ロゴスキップ |
| ドラゴンクエストIII（GBC版） | 通常プレイ・倍速プレイ |

経験値・お金の倍率は8・16・32・64・128・256倍から選べます。ROMの種類によってはゲーム固有の支援機能を利用できない場合があります。マロールの制限解除は未対応です。ドラゴンクエストI・IIは対応対象外です。

## 操作方法（Windows）

| 操作 | キーボード | コントローラー |
| --- | --- | --- |
| 移動・項目の選択 | 矢印キー | 十字キー |
| A・B | X・Z | A・B相当のボタン（NES配列） |
| Start | Enter | Start／＋ |
| Select | 右Shift | Select／− |
| 機能メニュー | F1／Esc | 左スティック押し込み |
| スロット1に保存 | F5 | LT |
| スロット1を読込 | F8 | 右スティック押し込み |

**速度・倍率・ON／OFFの変更は、機能メニューで項目を選んで左右を押してください。** A・Bの配置は設定で入れ替えられます。

## セーブデータについて

Windowsの通常セーブ・設定・ステートセーブは、`%APPDATA%\GBWiz`に保存されます。エクスプローラーのアドレス欄にこのパスを入力すると開けます。

セーブファイルの名前はROMファイル名に基づきます。ROMの名前を変えると、以前のセーブが見つからなくなる場合があります。バージョンを更新するときや支援機能を使う前には、保存先フォルダーをコピーしてバックアップしておくと安心です。

ステートを読み込むと、その保存時点に戻ります。通常のゲーム内セーブも併用してください。
