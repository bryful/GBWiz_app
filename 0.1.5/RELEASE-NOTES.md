# GBWiz 0.1.5

2026-11-19。Windows x64、Android 8.0以降（arm64-v8a／x86_64）向けです。

## 0.1.4からの変更

- 外伝I〜III・GBC版I〜IIIの自前マップで、未踏破の床を暗い青、踏破済みを明るい青で表示します。
- 原作の踏破記録を参照するため、既存セーブでも利用できます。GBC版はセーブ前の探索も反映します。
- 現在地は緑、選択位置は黄色で表示します。直接移動後の踏破判定は原作の更新タイミングに従います。

従来のキャラクター編集、マップ移動、支援機能、倍速、ステートセーブを継続します。
ソース・ROM・保存データ・秘密鍵・資格情報は同梱しません。操作はREADME.md、検証範囲はVALIDATION.mdを参照してください。
