# GBWiz 0.1.0-rc1

外伝1のサポート機能が一通り利用できる段階のリリース候補です。正式公開・Androidの正式署名は未実施です。

- WindowsプレビューとAndroidのGB／GBCプレイ、ROM選択・リセット。
- ROM名に基づく通常セーブ、5スロット、スロット1ショートカット。
- タッチ操作、Xbox／ProのNES配列、AB入替。
- 対象7作品の1.5／2／3／4倍速と主要場面の等速音声。
- 外伝1の経験値・お金倍率、作成ボーナス最大、MP消費なし、善悪混合、ロゴスキップ。
- 外伝1の対象キャラクターの全呪文習得・属性変更。
- 暫定アイコンAとWindowsのバージョン情報、Android adaptive iconを追加。

## 対応範囲

外伝2・3とGBC Wizardry 1・2・3は通常プレイ・倍速音声の既存対応を含みます。外伝1のサポート機能の展開は、この候補を区切りとして次に行います。DQ3は既存対応を維持します。DQ1&2は対応対象外です。

マロール制限解除は初期調査で高コストと判断して保留しています。未確認のROM版にはゲーム固有サポートを適用しません。
実物のコントローラー、全イベント、長時間プレイを網羅した確認ではありません。アイコンはユーザー選択前の暫定案です。

Windows全21テスト、Android release／debugビルドとrelease lint、Pixel 9aのアイコン・設定・操作・描画の10件が成功しています。正式リリース前の残件は対応ソース内のdocs/release-preparation.mdに記録しています。
