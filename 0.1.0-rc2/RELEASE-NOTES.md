# GBWiz 0.1.0-rc2

外伝1のサポート機能が一通り利用できる段階のリリース候補です。正式公開・Androidの正式署名は未実施です。

- WindowsプレビューとAndroidのGB／GBCプレイ、ROM選択・リセット。
- ROM名に基づく通常セーブ、5スロット、スロット1ショートカット。
- タッチ操作、Xbox／ProのNES配列、AB入替。
- 対象7作品の1.5／2／3／4倍速と主要場面の等速音声。
- 外伝1の経験値・お金倍率、作成ボーナス最大、MP消費なし、善悪混合、ロゴスキップ。
- 外伝1の対象キャラクターの全呪文習得・属性変更。
- ユーザー提供のWiizアイコンを元に、縦長のGB風カセットと「GBWz」の文字へ変更。Windows ICO・Android adaptive iconへ反映。
- 外伝2のMP消費なし、外伝2・3の善悪混合コア、GBC Wizardry 1〜3のロゴスキップを収録。

## 対応範囲

外伝2・3とGBC Wizardry 1・2・3は通常プレイ・倍速音声に加え、上記の低コスト展開項目を含みます。個別キャラクター編集や報酬倍率などの重い解析は保留しています。作品別の検証範囲はdocs/porting-status.mdを参照してください。DQ3は既存対応を維持し、DQ1&2は対応対象外です。

マロール制限解除は初期調査で高コストと判断して保留しています。未確認のROM版にはゲーム固有サポートを適用しません。
実物のコントローラー、全イベント、長時間プレイを網羅した確認ではありません。0.1.0-rc1は旧アイコンの候補として保持しています。

機能展開後のWindows全27テストとPixel 9aの起動・原作処理・操作8テストが成功しています。今回の変更はアイコンと候補のバージョン情報・説明です。正式リリース前の残件はdocs/release-preparation.mdに記録しています。
